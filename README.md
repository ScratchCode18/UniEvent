
# UniEvent 🎓

A University Event Management System designed to simplify
event organization, registration, and administration.

## Project Overview

UniEvent allows students to explore university events,
organizers to manage events, and administrators to
oversee event activities.

## User Roles

### Student
- View upcoming university events
- Register for events
- View registered events

### Event Organizer
- Create and manage events
- Edit and delete events
- View event registration counts

### Admin
- Review event approval requests
- Approve or reject events
- Manage registered users
